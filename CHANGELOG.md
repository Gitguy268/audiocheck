## [Unreleased]

### Added

- The first version: a page that checks audio files in the browser for lossy transcodes, fake hi-res (upsampling and padded bit depth), loudness, true peak, clipping and damage, with a spectrogram per file.
- Unit tests for the analysis, generated test audio and an end-to-end test that compares loudness and true peak with ffmpeg.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `NOTICE`, issue and pull request templates, `CODEOWNERS`, a Dependabot configuration, and workflows for CI and GitHub Pages.
